🚀 START ALL SERVICES (Automatic):

    .\scripts\start-all-quick.ps1

    This will open 2 terminal windows and start nginx in background.
    Then start Tomcat in your IDE.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 START MANUALLY (3 terminals):

Terminal 1 - Payment Service:
    cd payment-service
    npm start

Terminal 2 - AI Service:
    cd ai-service
    .\start-ai-service.ps1

Terminal 3 - Nginx:
    C:\Users\admin\Downloads\nginx-1.30.4\nginx-1.30.4\nginx.exe -c nginx\conf\nginx.conf

Then: Start Tomcat in IDE (NetBeans/IntelliJ)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🛑 STOP ALL SERVICES:

    .\scripts\stop-all-services.ps1

    (Also stop Tomcat manually in IDE)
